## Spacing exception rationales (UI-SPEC checker note, settled here)

- New lines pill 32px high: the shortest Nocturne button height that still fits Label 12 text plus a 14px icon with 8px vertical breathing room; it floats over text, so it stays below the 40px input.
- Spinner glyph 14px: matches the 14px body line it sits on, so the progress line has the same height as a feed line.
- Pinned-to-bottom threshold 48px: one feed line (14px at 1.6) plus the 8px gap is about 30px; 48px tolerates sub-line scroll drift and momentum scrolling without unpinning.
- Keyword underline offset: 4px (checker note; the UI-SPEC's 3px rounded onto the 4px grid).
