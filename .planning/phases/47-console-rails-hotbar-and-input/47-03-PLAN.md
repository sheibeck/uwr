Output: seven `src/rails/*.ts` modules and `src/hotbar/hotbar.ts`, each with a test. Components that render them come in 47-08, 47-10 and 47-11.

Note on CONTEXT "Cooldowns ... from ability_cooldown and item_cooldown": hotbar slots reference only `abilityTemplateId`; `item_cooldown` is keyed by a snake-cased item name and is written only by `use_item` for consumables. No column links a slot to an item (research S9, verified in spacetimedb/src/reducers/items.ts use_item), so no slot can carry an item cooldown. The sweep uses `ability_cooldown`; `item_cooldown` is not subscribed. This is recorded in the summary as missing data, not a scope choice.
