<objective>
Build the pure text layer of the feed: classify each event row (or local entry) into labelled line views, strip the old server markup from static lines, parse whisper, party-chat and NPC-says formats, and find soft-accent keywords in line text.

Purpose: CON-01 (labelled lines by kind) and CON-02 (keywords). CONTEXT "Feed: Rendering" and "Keyword detection is client-side"; Phase 46 contract A6 (text nodes only, segments literal). Research "Row classification", "Cleaning static server text (S4, required)", "Keyword matcher (Q11)". Research's NPC-says parse is used for no-segment npc rows (UI-SPEC said "whole message"; research shows the server writes 'Name says, "text"', so parsing gives the proper NPC line; fallback is the whole message in the NPC hue).

Output: four pure modules plus a server-parity test. No Vue components here (47-07 renders them).
</objective>
