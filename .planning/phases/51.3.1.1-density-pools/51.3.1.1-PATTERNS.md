### `data/density_rules.ts` (utility, transform)

**Analog:** `data/economy_rules.ts` L225-245 (splitmix64 rolls; reuse, do not copy) and `lootSeed`.

```typescript
export function economyRoll(seed: bigint, index: bigint): bigint {
  let z = BigInt.asUintN(64, seed + (index + 1n) * 0x9e3779b97f4a7c15n);
  z = BigInt.asUintN(64, (z ^ (z >> 30n)) * 0xbf58476d1ce4e5b9n);
  z = BigInt.asUintN(64, (z ^ (z >> 27n)) * 0x94d049bb133111ebn);
  return z ^ (z >> 31n);
}
export function rollBelow(seed: bigint, index: bigint, n: bigint): bigint {
  if (n <= 0n) return 0n;
  return economyRoll(seed, index) % n;
}
export function lootSeed(tsMicros: bigint, characterId: bigint, combatEnemyId: bigint): bigint {
  return BigInt.asUintN(64, tsMicros * 1000003n + characterId * 7919n + combatEnemyId * 104729n);
}
```

Apply: `import { economyRoll, rollBelow, pickWeighted } from './economy_rules'`; define `POOL_ROLL` as a fixed-index const object (never additive offsets); `encounterSeed(ts, leaderId, placeId, phase)` follows the `lootSeed` multiply-and-add-primes shape. One `Object.freeze` constants block; no `ctx`, `Date`, `Math.random`, no `helpers/` imports. Chance and draw bodies: RESEARCH Pattern 3 (L525-540).

## Shared Patterns

### Module-identity guard (every scheduled reducer)
**Source:** `index.ts` L447-449; pinned textually by `scheduled_guard.integration.test.ts` L19 (`GUARD` const, within 700 chars of `scheduledReducers['<name>']`).

### Ownership / refusal
**Source:** `requireCharacterOwnedBy(ctx, characterId)` (throws `SenderError` for missing/foreign character), then `fail(ctx, character, msg)` for in-game refusals (owner preference over `SenderError`).
**Apply to:** `pull_family`, `gather_pool`, `pull_named_enemy`.

### Single fight roster rule
**Source:** `helpers/group.ts` L10-35 `fightRoster(initiator, candidates, inOtherFight?)` (online, same place, de-duped, initiator kept).
**Apply to:** every pool fight start including travel (re-read travellers after all `moveOne`).

**Source:** `economyRoll`/`rollBelow`/`pickWeighted`/`pickWithoutReplacement` in `data/economy_rules.ts` (L231, L239, L517, L536). No `Math.random`, no `% 100n` of a timestamp.

**Source:** `schema/economy_privacy.test.ts` L1-12 plus `helpers/combat_fight_fixture.ts` exports (`T0` L13, `MODULE` L16, `ALICE` L18, `fightSeed` L139, `startSeed` L229, `fightCtx` L245, `rows` L249, `openTickArg` L254). New `helpers/pool_fixture.ts` builds on these.
