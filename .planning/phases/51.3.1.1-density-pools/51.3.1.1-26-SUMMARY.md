# Phase 51.3.1.1 Plan 26: NPC rumour line Summary

NPCs now hear the region's recent population shifts: talk_to_npc reads the pool engine's rumour rows (`recentRumors`) into `NpcConversationInput.regionRumors`, and the npc_conversation user message carries the owner-approved section C line right after the "Enemies in the area" line, only when there is news.

- **Fix:** Items are filtered after `w()`. When none is left, no line prints and the output is byte-identical.
