## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| server -> every client (public tables) | Public rows are visible to every client |
| client -> scheduled reducer | Any client can call a scheduled reducer with a forged argument |
| deploy -> live database | A publish can destroy state (a clear wipes the stored Anthropic key) |
