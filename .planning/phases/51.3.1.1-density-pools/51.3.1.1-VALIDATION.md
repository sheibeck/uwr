## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 5.0.2 (server mock-ctx and schema-recorder tests; Vue Test Utils + happy-dom for client) |
| **Config file** | none (`vite.config.ts` has no `test` key; per-file `// @vitest-environment happy-dom` where needed) |
| **Quick run command** | `npx vitest run <touched test files> --maxWorkers=1` |
| **Full suite command** | `npx vitest run --maxWorkers=1` and `npx vue-tsc -b` (repo root) |
| **Estimated runtime** | quick 10–30 s; full about 16 min on one worker |

Recording-server mock pattern (copy exactly): `vi.mock('spacetimedb/server', async () => (await import('../helpers/schema_recorder')).createRecordingServerMock());` then `await import('./tables')` in `beforeAll`; reducers via `capturedReducer(name)`; fights via `fightCtx(seed, sender)`; strict mock db via `createMockDb(seed, { strict: true })`.

---

## Sampling Rate

- **After every task commit:** run the touched test files with `--maxWorkers=1`.
- **After every plan wave:** `npx vitest run spacetimedb/src --maxWorkers=1` (server waves) or `npx vitest run src --maxWorkers=1` (client waves), plus `npx vue-tsc -b`.
- **Before `/gsd-verify-work`:** full suite green except the three baseline files, `vue-tsc -b` exit 0, live migration checks recorded.
- **Max feedback latency:** 30 seconds per task.
