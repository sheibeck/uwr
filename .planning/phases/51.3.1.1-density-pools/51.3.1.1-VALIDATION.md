## Sampling Rate

- **After every task commit:** run the touched test files with `--maxWorkers=1`.
- **After every plan wave:** `npx vitest run spacetimedb/src --maxWorkers=1` (server waves) or `npx vitest run src --maxWorkers=1` (client waves), plus `npx vue-tsc -b`.
- **Before `/gsd-verify-work`:** full suite green except the three baseline files, `vue-tsc -b` exit 0, live migration checks recorded.
- **Max feedback latency:** 30 seconds per task.
