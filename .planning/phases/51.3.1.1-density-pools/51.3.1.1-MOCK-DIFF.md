## 6. Server data the mock needs that the decisions do not cover yet
- Family display fields: plural and singular nouns ("goblins"/"goblin"), an ambush "burst" phrase, an icon or creature-type key, and a level range per family per place.
- Density line per family (or noun slots for templates) for levels 0-3; resource lines for levels 1-3 and an icon key per resource kind.
- Per place: a short name for mobile chips, a kind word, a noun for the empty-resource line, and the home level per family/resource (for "settles" and regrowth).
- Rating per viewer: needs the viewer's level, so either a shared `@game-data` rating rule over public pool rows or a per-sender view; the rating line copy.
- Combat: the encounter origin (pull / enter / leave / named) and the population word at pull time for the source line; each enemy's current target or heal target; enemy role per member.
- Harvest cap per player per place: amount left and window reset, so Gather can be disabled with a reason.
- Gather yield by density (if MD-16 is adopted).
- Feed events for density changes at a place (kills, hunters, vacuum), delivered to players present.
- Named/boss respawn state ("back after a long rest") if MD-18 is adopted.
- Pending vacuum ("moves in on the next tick") and admin set-level / force-ambush (if MD-24 is adopted).
