# Phase 51.3.1.1 Plan 21: Map rating ring, legend and detail; feed line kinds Summary

The Map's node rings, captions, detail tag, aria labels and legend now use the same safety rating as the rails (`ratingForPlace`, `rate-*` classes). The feed draws the four new server kinds: the tinted ambush band and the `density_down`, `density_gone` and `travel_quiet` icon lines. **Open:** the two Map callers (`useMapGraph.ts`, `useDestination.ts`) are outside the file list and still have to pass the rating source. Until they do, the live Map reads Unknown for every non-safe place.

## What was built

### Task 1: Map (commits fc36c13e RED, 832d213d GREEN)
- **`nodeView.ts`**
  - `MapRatingSource { pools, poolsApplied(id), ratingLevel, bossOrNamed(id) }` uses the same input shape as Plan 20's exits.
  - `mapPlaceRating(place, source)` returns `{ view: PlaceRatingView, range }`.
  - `ratingCaption(view)`: 'Risky · Lv 4–5'; the word alone when the place has no family; the range alone while Unknown; '' for Safe.
  - `RATE_COLOR` maps each rating key to its token.
  - `NodeView`: `danger` is replaced by `rating`. `levelColor` is now the `rate-*` class. `caption` is new. `levelLabel` is 'Safe' / 'Lv a–b' / ''.
  - `nodeAriaLabel` takes `rating` + `range`. It reads `..., level 4 to 5, risky` and `..., safe`. An Unknown place speaks only its range. An uncharted place speaks neither.
- **`detailModel.ts`**
  - The `dangerTag` options:
    - Rated: `{Rating} · Lv a–b` with the sword in `RATE_COLOR`.
    - Safe: shield.
    - Uncharted: question icon, 'Danger unknown'.
    - Loading: the range alone in neutral, or no tag.
  - The region line and the crossing keep the band chip (B9).
- **`GraphPlane.vue`**
  - The node and caption classes come from `view.levelColor`.
  - The ring rules are `rate-safe|quiet|risky|deadly`: visited 2px, heard of 45%. `rate-unknown` keeps the dashed neutral ring.
  - `.level.rate-*` colours the caption.
  - The desktop sub-line is now flex: `.sub-text` ellipsizes, then the shield, then `·` and the caption (flex: none).
  - The mobile inline caption uses the same class.
  - Still one `<svg>`. No literal colours. No Overrun mark (B6). Gate pills unchanged (B9).
- **`MapLegend.vue`**: Safe, then `Safety for Lv {n}:` and Quiet, Risky, Deadly (words from `@game-data/place_rating` `RATING_WORDS`) in `.rate rate-*` classes.

### Task 2: Feed (commits 1b94a395 RED, 4b765ae7 GREEN)
- **`lines.ts`**: a `DENSITY_KINDS` Map turns the server kinds `ambush`, `density_down`, `density_gone` and `travel_quiet` into the line kinds `ambush`, `densityDown`, `densityGone` and `travelQuiet`. They are classified after `cleanServerText`, are never keyword-eligible, and a blank row draws no line. Unknown kinds still fall back to system.
- **`FeedLine.vue`**:
  - `div.line-ambush`: flex, gap 8, padding 8px 16px, `--radius-md`, background `color-mix(in srgb, var(--color-health) 24%, var(--color-surface))`, `PhWarning` 16 in `--color-con-orange`, body 14 / 500 in `--color-text`.
  - `PhTrendDown`, `PhSkull` and `PhFootprints` 12px icon lines in Label 12, in the neutral tones the UI-SPEC gives.
  - No animation. Text renders as text nodes only.
