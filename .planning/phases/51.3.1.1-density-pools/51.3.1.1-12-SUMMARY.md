# Phase 51.3.1.1 Plan 12: Gathering from shared pools Summary

Gathering now draws from shared resource pools. The new `gather_pool` reducer checks the per-player, per-place harvest cap, the resource's time of day and an empty pool, and at a place that is not safe it can roll an ambush from the creature pools. `finish_gather` pays out by density level, then the gather dial, then the perk bonuses, and depletes the pool by 17 points. Passive search no longer creates personal resource nodes.

## What was built

### Task 1: harvest cap helpers (`helpers/harvest.ts`)
- `harvestRow(ctx, characterId, locationId)` returns the pool_harvest row of a character at a place (looked up through `by_character`), or null.
- `harvestCappedFor(ctx, characterId, locationId, now)` returns `isHarvestCapped` over that row.
- `recordHarvest(ctx, characterId, locationId, now)` applies `nextHarvest` and then inserts or updates the row (one row per character and place). After the window has passed, the next gather starts a fresh window with `cappedUntilMicros` 0n, so `my_harvest_caps` stops listing the place.
- `gatherDurationMicros(ctx, character)` is the 8 s cast shortened by the `gatherSpeedBonus` perk, never below `MIN_GATHER_MICROS` (0.5 s). Both `gather_pool` and `start_gather_resource` use it.

### Task 2: `gather_pool` and the `finish_gather` pool path
- **`gather_pool({ characterId, poolId })` (reducers/pools.ts)** checks, in order:
  - `requireCharacterOwnedBy`;
  - in combat or already gathering;
  - the pool is missing, at another place, or a creature pool (or its item template or place is missing): "That is not here.";
  - time of day: `outOfTimeRefusal(resource, nightOnly)`;
  - settle, then level 0: `exhaustedRefusal(resource, placeNounFor(location))`;
  - `harvestCappedFor`: `harvestCapRefusal()`.
- **The ambush.** At a place that is not safe, `gather_pool` rolls `rollEncounter` with phase 'gather', `GATHER_AMBUSH_FACTOR_PCT` and the roster's lowest level.
  - On a hit it calls `drawGroup`, then `startPoolFight` with origin 'ambush_gather' and an 'ambush' line (`ambushLine({ phase: 'gather', resource, ... })`, "While you gather iron ore, ...!"), and returns without gathering.
  - On a miss it inserts `resource_gather { nodeId: 0n, poolId }` and the tick, and writes "You begin gathering {name}." to the player and the group.
- **`finish_gather` with `poolId > 0n`** (`finishPoolGather` in the closure):
  1. Deletes the gather row.
  2. Pays nothing when the character has left the place or is fighting.
  3. Settles the pool. At level 0 it prints the exhausted line and stops.
  4. Otherwise the quantity is `gatherYield(yieldForLevel(level), loadEffectiveDials(ctx, pool.regionId).gatherRatePct)`, then `applyGatherBonuses`. A modifier reagent yields exactly 1.
  5. Adds the items and writes `gatherResult` (+ any bonus text) through `logPrivateAndGroup`.
  6. Calls `applyDepletion(GATHER_DEPLETION_POINTS, 'gather')` and `recordHarvest`.
  7. When the pool reaches 0, adds `lastGatherLine` after the result.
- **Shared bonuses.** The perk and racial bonuses moved into a module-level `applyGatherBonuses(ctx, character, quantity, seedId)` that both paths use, with the same seeds as before (the node id, or the pool id).
- **Legacy node path.** It is unchanged for `nodeId > 0n`; a missing node deletes the row.

### Task 3: passive search
- `performPassiveSearch` no longer has the resource roll, the `spawnResourceNode` loop or the "You discover some resources." line. `foundResources` is always false.
- It still cleans up old personal nodes at the place, discovers quest items and named enemies, and inserts `search_result`. The unused `spawnResourceNode` import is removed. The file is still CRLF.
