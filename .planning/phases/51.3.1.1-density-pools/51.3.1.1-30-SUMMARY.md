## Deviations from Plan

1. **[Coordinator / owner D-71] The `Feud: none.` variant.** The plan's behavior said "a feudCount outside 2..3 prints no Feud line". The approved R2-A2 (8664dd61) adds `Feud: none.` for a region that rolls no feud. A feud count of 0 now prints exactly `Feud: none.`, and 1, 4, non-integers and a missing count still print no Feud line. The tests cover both forms, and `buildWorldFillInput` is checked for one region id with a feud and one without.
2. **[Rule 3] Snapshot outside files_modified.** `spacetimedb/src/data/__snapshots__/llm_schemas.test.ts.snap` was refreshed with `-u`. The change is only the two FAMILY_ITEM fields in REGION_FILL_SCHEMA. It was unmodified in `git status` before, and no running plan lists it.
3. **[Rule 2] The hostile fixture.** The shared hostile fixture in `llm_layers.test.ts` (a file this plan lists) gained `familyHistories`, so the route-wide injection matrix covers the new line too, as Plan 26 suggested.
4. **The pre-edit capture file.** The Plan 26 output with a rumour, used for byte identity, was captured by a temporary test file (`data/p30_capture_tmp.test.ts`). It was run once, deleted at once and never committed. The no-rumour captures equal Plan 26's `BEFORE_FULL`/`BEFORE_BARE` byte for byte.
