Close the owner-reported gap from 2026-10-06: "My Elfansworth character has a bunch of items in his bag, but I'm unable to discover any recipes." Today `recipe_template` is empty and `research_recipes` only reveals existing rows. This plan implements the CONTEXT owner decision "recipe generation", with no LLM involved.

At a station, Discover recipes builds recipes by rule from the materials the character carries:
- Material kind maps to category.
- Material tier sets quality, through the existing `craftQualityForMaterialName` at craft time.
- The area level band sets the output level.
- Names are composed from vocabulary words.

Each recipe and its output template are stored once under a stable key and shared by every character. A generated recipe must craft end to end, and the Phase 50 client shows it unchanged. The server is then published to the owner's local database only.
