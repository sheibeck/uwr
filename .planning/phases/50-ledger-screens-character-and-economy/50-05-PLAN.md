Facts verified during planning (items.ts at planning time):
- `buy_item` (105-152): perk percent `getPerkBonusByField(ctx, character.id, 'vendorBuyDiscount', character.level)`; when > 0: `finalPrice = price * BigInt(100 - Math.min(perk, 50)) / 100n`, minimum 1n, and `discountMsg = ' (' + perk + '% perk discount)'`; then when `character.vendorBuyMod > 0n`: `finalPrice = finalPrice * (1000n - vendorBuyMod) / 1000n`, minimum 1n. Message `You buy {name} for {finalPrice} gold.{discountMsg}`.
- `sell_item` (154-217): `baseValue = BigInt(vendorValue ?? 0) * BigInt(quantity ?? 1)`; perk `vendorSellBonus` > 0 and base > 0: `base * BigInt(100 + perk) / 100n` with `sellBonusMsg`; then `computeSellValue(value, character.vendorSellMod ?? 0n)`.
- `sell_all_junk` (219-250): the same per instance, summed (rounding happens per instance).
- `helpers/economy.ts:10-15` `computeSellValue(baseValue, vendorSellMod)`: when both > 0, `baseValue * (1000n + mod) / 1000n`, else baseValue. It is imported by index.ts (~198) and reducers/intent.ts:6.
- `BigInt(non-integer number)` throws, so a perk percent passed from Number math must be truncated (Math.trunc) before BigInt.
- Plan 03 made getPerkBonusByField delegate to perkBonusByField; pool key `shrewd_bargainer` gives vendorBuyDiscount 5 and vendorSellBonus 5.
