### CR-01: prompt_draft.mjs emits and writes text from an unapproved draft, and can return the raw owner bullet as the "chosen line"

**Files modified:** `scripts/llm/prompt_draft.mjs`, `scripts/llm/prompt_draft.test.mjs`
**Commit:** 823b3ef1
**Applied fix:**
- **Approval gate.** `chosen`, `pins`, `write` and `check` (`APPROVED_ONLY_MODES`) refuse a draft whose status line is not `Status: APPROVED YYYY-MM-DD`. They exit 1 with `<mode>: draft is not APPROVED (...)`, and `write` writes nothing.
  - `parseDraft` reads the status line from the header only: before the first `## ` heading and outside fences. The date must be a real calendar date.
  - `ownerChoices` itself refuses an unapproved draft (`assertApproved`).
- **No bullet fallback.** A choice whose variant can't be found throws. The raw-bullet result is allowed only for keys listed in the new `raw` option, and only when their section has no labelled fences.
  - The `chosen` command passes `RAW_BULLET_CHOICES = ['6']`.
  - Any other key with no `**Recommended**` / `**Alternative**` fence throws. The review's 7a reproduction is now a test.
- **Quoted edits fail.** A quoted text on a RECOMMENDED or ALTERNATIVE bullet must equal the chosen fence. Otherwise it throws: bullet edits are not supported, so the owner edits the fence.
- **Repeated keys fail.** A choice key listed twice throws.
- **Shipped output is unchanged.** I captured the output before and after the change and compared it with `cmp`:
  - `chosen` output: identical.
  - `pins` for `## 1.`: length 4099, sha256 a27e15b5...: identical.
  - `pins` for `## 2.`: length 3223, sha256 965039cb...: identical.
  - `check`: MATCH for both WORLD_GEN_BLOCK and WORLD_GEN_FAMILIES_BLOCK.
- **Tests:** 49 pass in prompt_draft.test.mjs (13 new).
  - Header-only and fenced status lines.
  - Invalid dates.
  - Refusal of an unapproved draft, both in the function and through all four CLI modes in a temp folder.
  - The 7a missing-labels reproduction.
  - The raw-key rules.
  - A quoted edit on a RECOMMENDED bullet.
  - Repeated keys.
