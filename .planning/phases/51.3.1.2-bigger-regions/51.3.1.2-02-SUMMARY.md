# Phase 51.3.1.2 Plan 02: Region size and shape rules Summary

Seeded 8-10 place count with a floor of 6, plus pure graph rules for a bigger region: orphan repair to the least-connected reached place, a 4-exit cap that trims only non-bridge edges, a +1-per-2-hops level gradient capped at +2, a 4-host floor and the farthest-place boundary anchor. All of them are named DENSITY_RULES constants in a deterministic module. Nothing calls them yet; Plan 05 wires them into the writer.

## What was built

**Task 1 (D-03, D-10):**
- Eight constants in a new commented block of `DENSITY_RULES`: REGION_PLACES_MIN 8, REGION_PLACES_MAX 10, REGION_PLACES_FLOOR 6, LEVEL_HOPS_PER_STEP 2, LEVEL_OFFSET_MAX 2, EXIT_DEGREE_CAP 4, MIN_HOST_PLACES 4, ECONOMY_MEDIUM_MIN_PLACES 8.
- `POOL_ROLL.PLACE_COUNT: 89n` (checked first: 89n was free).
- `placeCountFor(regionId)` = REGION_PLACES_MIN + rollBelow(hubSeed(regionId), PLACE_COUNT, 3). It reads no timestamp.
- `acceptedNewPlaces(usable, placeCount)` returns `{ keep, ok }`:
  - with a count, keep = min(usable, placeCount - 1), and ok means keep + 1 >= 6;
  - with null, keep = min(usable, 9) and ok is always true;
  - NaN, negative and fractional inputs become whole numbers.
- familyCountFor 8/9/10 is pinned at 12/13/15 (SC3).

**Task 2 (D-04, D-05):**
- `shapeRegionEdges({ count, edges })` works in three steps:
  - **Clean:** drops self loops, non-integer or out-of-range indices and duplicate pairs.
  - **Repair:** links the lowest unreached index to the reached node with the fewest edges. Ties go to the smaller hop distance, then the lower index.
  - **Trim:** while a node is over the cap, takes the over-cap node with the most edges (ties lowest index) that has a non-bridge edge. It removes the non-bridge edge whose other end has the most edges (ties highest index).
  - Every loop is bounded. The output is sorted.
- `hopsFrom(count, edges, start)` is a BFS; an unreached node gets -1.
- `levelOffsetForHops(arrivalOffset, hops)` = arrivalOffset + min(2, floor(hops / 2)).
- `hostFloorFlips({ nodes, hops })` returns the farthest safe non-hub places, in pick order, until 4 places can host creatures. It never returns a hub.
- `boundaryAnchorFor({ nodes, hops })` picks the farthest non-safe non-hub place (ties lowest index). Otherwise it picks the farthest place of any kind, and returns 0 when there are no nodes.
- Guard registration in `density_phase_guard.test.ts`:
  - `'data/region_shape.ts'` is added to POOL_MODULES;
  - a new case asserts that DENSITY_RULES carries the eight names.
  - The existing "no other source file assigns one of its names" case already covers the new names: region_shape.ts only reads `DENSITY_RULES.X`.
