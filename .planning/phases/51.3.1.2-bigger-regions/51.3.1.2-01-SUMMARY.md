# Phase 51.3.1.2 Plan 01: Prompt-draft approval record and copy tool Summary

The owner's approval of the 51.3.1.2 prompt draft is on record with the chosen lines resolved from the draft itself. `scripts/llm/prompt_draft.mjs` is a tested, network-free tool. It reads the draft, resolves each chosen variant (and checks a quoted choice against its fence), writes an approved block into a named `llm_layers.ts` template literal, and proves the copy with MATCH or the first differing index, plus length and sha256.

## What was done

### Task 1: Pure draft functions (RED 9f0c38dc, GREEN 1b4cf500)
- `parseDraft(text)` throws on a carriage return and returns `{ status: { approved, date, line }, lines }`.
- `ruleBlock(lines, heading)` returns the block between the first two `---` lines of the section, with blank edges trimmed. It throws naming a missing heading, or when the two rule lines are missing.
- `fencedBlocks(lines, heading)` returns `{ label, text }[]`.
  - The label is `'recommended'`, `'alternative'` or null, read from the nearest preceding non-empty line.
  - A section ends at the next heading of the same or a higher level. A `#` line inside a fence does not end it.
  - An indented fence has its opening indent stripped.
- `ownerChoices(text, { required })` reads the `## Owner choices` bullets, including wrapped continuation lines.
  - It maps `Section N` to `## N.` and `Nx` to `### Nx.`.
  - It throws when the named variant's fence is missing or ambiguous, or when the first backtick quote of an ALTERNATIVE bullet differs from the fence. The message gives the differing index.
  - It also throws when a required key is missing.
  - A section with no labelled fences (section 6) yields the raw bullet text.
- `substituteNaming`, `templateBody`, `evaluateBlock`, `writeTemplate`:
  - `evaluateBlock` reads a template literal as JavaScript does: CRLF becomes LF. It refuses a backslash or any interpolation other than `${WORLD_NAMING_RULES}`.
  - `writeTemplate` replaces only the named const, exported or not. It keeps a CRLF source's line endings and treats `$&` literally. It throws on a backtick, a backslash, any `${`, or a missing or duplicate const.
- `firstDiff`, `sha256Hex`, `compareBlock` (`{ match, index, length, sha256 }`, length and hash of the shipped text).

### Task 2: Command line (bd7d7963)
- `node scripts/llm/prompt_draft.mjs <mode> <draft> [args]` (paths relative to the current directory). It runs only when the file is the main script.
- `status` exits 1 unless APPROVED with a date.
- `chosen` requires keys 5, 6, 7a to 7e (`REQUIRED_CHOICES`).
- `check` exits 1 on a difference.
- An unknown mode or missing arguments print the usage and exit 1.
- One test runs `chosen` through `execFileSync(process.execPath, ...)` and compares the parsed JSON with `ownerChoices`.
