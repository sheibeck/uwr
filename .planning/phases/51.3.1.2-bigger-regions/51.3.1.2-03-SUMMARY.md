# Phase 51.3.1.2 Plan 03: Map and exits proven on 10-place regions Summary

Three 10-place map fixtures (a tree with a town hub, a chain and a nine-place ring with a chord and two border places) now run through the full layout invariant suite in all three modes. A six-exit place now runs through the exits list. Both pass with no production change.

## What was done

### Task 1: Three 10-place map fixtures (commit 49e51552)
- `TREE10` (region 9001n): arrival point `Saltreach Landing` (bind stone) linked to the town hub `Corran Market` (4 in-region edges). The tree branches out to `The Edge Beyond Saltreach` (uncharted). One border place, `Fennick Hollow` of region 9000n, is linked to the arrival point.
- `CHAIN10` (region 9002n): a single chain from `Marrow Landing` to `The Edge Beyond Marrow`, with border `Dunmore Gate` (9000n) on the arrival point.
- `RING10` (region 9003n): a ring of nine places with the chord 9303-9307. The doorway `The Edge Beyond Kelp Harbour` hangs off 9305, the ring place farthest from the arrival point (four hops). There are two border places: `Brine Steps` (9000n) on the arrival point and `Cold Orchard` (9004n) on ring place 9307.
- All three were appended to `FIXTURES`. The suite runs cases (a) to (h), whole pixels and the neighbour side for each fixture in desktop 652 x 600, mobile 358 x 320 and no-canvas modes.
- A comment cites Phase 51.3.1.2 (SC1). It says stars are left out because the server degree cap prevents them.
- Result: `npx vitest run src/map/graphLayout.test.ts --maxWorkers=1`: 238 passed, including 90 new cases. Every invariant held on the first run, with no timing flake.

### Task 2: A place with six exits (commit f2eacf68)
- New describe `exitRows, a place in a bigger region (Phase 51.3.1.2, SC1)`. Routes from `Ember Gate`:
  - four in-region places: Gloamwood (woods), Haven (town), Larkspur Meadow (plains) and Hollowcrag (mountains);
  - the source-region passage, Brackwater (region 2n);
  - the uncharted doorway, Beyond.
- Assertions:
  - six rows in route order;
  - each row has its own name and aria label;
  - six distinct notes, all exact strings;
  - the one crossing row's note starts with `New region`, with the accent tone and the Cross button;
  - the doorway reads `Danger unknown` with terrain Uncharted;
  - every non-crossing row has the Travel button.
- Result: `npx vitest run src/rails/exits.test.ts --maxWorkers=1`: 27 passed.
