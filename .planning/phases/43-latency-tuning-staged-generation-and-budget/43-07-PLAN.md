<objective>
Stage world generation (LAT-03): a small stage-1 job reveals the region, its start location and its first NPC and, inside the same apply transaction, enqueues the stage-2 fill job; stage 2 fills the rest; a stage-2 failure leaves a playable region. The server posts the milestone line when stage 1 lands (LAT-05, server half).

Purpose: CONTEXT "Staged world generation" (two stages, applying stage 1 enqueues stage 2 with stage 1 passed in as facts, stage-2 failure keeps the region playable with an in-voice line, stage-1 content appears to all players at once, milestone line when stage 1 lands). RESEARCH Pattern 1, Pitfall 8 and "Staged Generation: Schema and Prompt Sketches". Greenfield rule (memory): the monolithic region writer is deleted, not kept as a shim.
Output: staged world-gen helpers, staged apply and failure handling, migrated unit and characterization tests, and the cutover trigger assertions flipped to world_gen_start. The sweeper and the explore retry are Plan 43-10.
</objective>

## Trust Boundaries

|----------|-------------|
| model reply -> public world tables | stage-1 and stage-2 replies become shared rows every player sees |
| stored stage-1 rows -> stage-2 prompt | model text is fed back to the model |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-43-24 | Tampering (prompt injection carried forward) | buildWorldFillInput | medium | mitigate | Facts are read from rows and sanitized by buildWorldFillVolatile (Plan 43-04); stage 2 never re-emits stage-1 fields |
| T-43-25 | Tampering (bad numbers) | writeRegionStart, writeRegionFill | medium | mitigate | toBigIntSafe on every model number; enemy levels clamped from the region danger as before |
| T-43-26 | Denial of service (stuck player) | stage-2 failure | medium | mitigate | FILL_ERROR keeps the region playable with services; nothing auto-retries; the explore retry lands in Plan 43-10 |

| T-43-28 | Information disclosure | world_gen_state.errorMessage (public) | low | mitigate | Only fixed in-voice lines are stored |
| T-43-SC | Tampering | package installs | low | accept | No packages installed |
