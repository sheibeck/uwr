## Flagged assumptions (unresolved edge rows, 43-EDGE-COVERAGE.md)

- **[FLAGGED ASSUMPTION, LAT-06, unresolved edge row; confirm at verify]** The parallel-class decision is made once, by `lat06Decision` over the recorded post-staging `creation_class_reveal` latencies (the Run A chosen-effort cell plus the Run B calls, each plus a 300 ms dispatch allowance), against a 10,000 ms p50 threshold (exactly 10,000 ms is leave_out). The p50, p95 and verdict are written to `llm_measurements.json` whichever way it falls. A declined or deferred sweep records verdict not_measured and parallel generation stays out. A build verdict stops this plan and returns to the orchestrator for a gap-closure plan (the research design: enqueue the reveal for both archetypes in one transaction after the race is interpreted, keyed by archetype, discarding the unchosen one), because the build needs the measured number the planner did not have.
