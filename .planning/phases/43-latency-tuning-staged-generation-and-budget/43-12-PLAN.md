## Flagged assumptions (unresolved edge rows, 43-EDGE-COVERAGE.md)

- **[FLAGGED ASSUMPTION, LAT-04, unresolved edge row; confirm at verify]** If stage 2 of class generation fails, expires or is refused, the class name, description and first ability stay on the creation state (CLASS_FILL_ERROR) and stay visible. The missing stats and abilities are generated later: any input retries stage 2 only. There is NO fallback to static default abilities, because CONTEXT locks "confirmation waits for stage 2" so every character enters the world complete. Creation never dead-ends: a retry or a go-back to the archetype choice is always one input away; while the kill switch or the ceiling holds, the retry answers with the resting line and go-back still works.
