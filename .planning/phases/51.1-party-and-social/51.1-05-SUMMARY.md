## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Robustness] verifiedEmailFromAuth never throws**
- **Found during:** Task 1
- **Issue:** The platform parses the token payload lazily inside the `senderAuth.jwt` getter, and `parseJsonObject` can throw there. With the switch off, login_email would then still fail, so the rollback would not be "exactly as before".
- **Fix:** The read is wrapped in try/catch, and a parse failure counts as "no email". An extra test covers it.
- **Files modified:** spacetimedb/src/helpers/login_identity.ts, spacetimedb/src/helpers/login_identity.test.ts
- **Commit:** 3958b8c5

**2. [Process] The partial summary was first kept outside the phase dir**
- While Task 3 was open, the partial summary sat in the coordinator scratchpad, so GSD would not count the plan complete before the owner answered. It was moved here after the approval.
