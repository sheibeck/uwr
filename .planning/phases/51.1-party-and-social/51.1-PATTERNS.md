## Shared Patterns

### Per-sender private data via view
**Source:** `spacetimedb/src/views/visited.ts` 16-28. **Apply to:** `my_friend_list`, `my_friend_request_list`. Resolve the caller with `ctx.db.player.id.find(ctx.sender)`, then indexed lookups only; return `[]` when no player or no `userId`.

### Guarded scheduled reducer
**Source:** `reducers/auth.ts` 57-61, `index.ts` 423-429. **Apply to:** `expire_group_invite`, anything else scheduled. First statement is the module-identity check; add to `SCHEDULED` in `scheduled_guard.integration.test.ts`.

### Refusal text
**Source:** `groups.ts` 18-19 (`failGroup` -> `fail(ctx, character, message, 'group')`). **Apply to:** every new group reducer path. The friend accept/reject/remove reducers have no character, so they keep `SenderError`.

### Client hub scope and keyed bindings
**Source:** `src/map/mapData.ts` 77-127, 275-286. **Apply to:** `socialData.ts`. One `effectScope`, `createKeyed` per subscription, filter equal to query, `reset` plus `dispose`.

### Inert default through injection
**Source:** `src/map/mapContext.ts` 83-138; components do `inject(KEY, createInertX())`. **Apply to:** every Social component, `PartyBlock.vue`, `NearbyList.vue`.

### Action sending with pending and rejection
**Source:** `src/ledger/actionRunner.ts`, NearbyList.vue 46-56. **Apply to:** all menu and Social actions. Nothing optimistic; rows drive state.

### Real-handler server tests
**Source:** `views/visited.test.ts` 54-75 (`noScanDb`, `createMockDb(seed, { strict: true })`), `reducers/passage_sweep.integration.test.ts`, `helpers/test-utils.ts` (`createMockCtx` has no `senderAuth`: add it in the CR-01 test). Fixtures that seed `player.activeCharacterId` (`passages.test.ts`, `passage_sweep.integration.test.ts`, `combat_fight_fixture.ts`) must also seed `character.online` once `onlineCharacterIds` is swapped.

### Design guards
No literal colors, no `v-html`, no `<svg`, Phosphor icons only, sizes 10/12/14/20, weights 400/500, spacing on the 4-based scale, text nodes only, never "ripple".
