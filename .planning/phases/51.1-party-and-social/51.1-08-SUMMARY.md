# Phase 51.1 Plan 08: Player Menu Rules and Party Actions Summary

Every party and player menu now comes from one tested pure function, and every party action goes through one tested action layer. `playerMenuEntries` returns ordered groups (`party`, `social`, `leader`) with the UI-SPEC labels, one disabled hint per entry, distinct icon ids and the Leave and Remove confirmations. `createPartyActions` sends each party reducer once with object arguments through the existing action runner, and has no path that joins a party except accepting an invite.
