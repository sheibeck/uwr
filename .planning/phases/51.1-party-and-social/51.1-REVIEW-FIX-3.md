## Fixed Issues

### WR-01: The re-invite wait can still be skipped with a second character

**Files modified:** `spacetimedb/src/helpers/group_invites.ts`, `spacetimedb/src/reducers/characters.ts`, `spacetimedb/src/reducers/groups.integration.test.ts`
**Commit:** 71bc8aa2
**Status:** fixed: requires human verification (rule change, logic)
**Applied fix:**
- `startsReinviteWait(reason, opts)` no longer looks at the actor. A `declined` or `cancelled` end starts the wait, and so does every `withdrawn` end unless `opts.deletion` is true. `expired` starts none.
- `endInvite` and `finishInvite` take an optional last argument `{ deletion?: boolean }` (exported type `EndInviteOptions`). `delete_character` passes `{ deletion: true }`, so a deletion keeps the no-wait rule.
- `settleGroupAfterLeave`'s `empty` branch no longer looks up the leaver or passes an actor; it withdraws each invite, which now starts the original inviter's wait.
- Tests: "a withdrawal the inviter did not cause starts no wait" became "a withdrawal another member caused starts the wait for the original inviter" (expects the A→C wait row). Added "deleting the invited character starts no wait", "deleting the inviter starts no wait", and the two-character loop (Ann and Bram form a group, Ann invites Cole, Ann leaves, Bram leaves; ten rounds send Cole one invite line).

**Commits:** 923b70fb (code and integration tests), bf345588 (two helper tests that still pinned the old silent dissolve)
**Status:** fixed: requires human verification (notice rule, logic)
**Applied fix:**
- `finishInvite` drops the `loneId !== invite.fromCharacterId` exclusion. The lone member's own reason line now gets " The group has disbanded." whenever the end dissolves his group, including a solo inviter's auto-group.
- Tests updated to the new rule: the solo-inviter decline, expiry and delete cases in `groups.integration.test.ts` (five existing assertions), and the expired and cancelled `endInvite` cases in `group_invites.test.ts`.
- Added the review's scenario for leader Bram (Bram leads {Ann, Bram}, invites Cole, Ann leaves, then Cole declines, the invite expires, or Bram cancels): each gives Bram his own line with the suffix.
