# Phase 51.3 Plan 06: Regional crafting (4th requirement, research, quality, salvage) Summary

Crafting now handles regional recipes on the server. recipe_template has a defaulted 4th requirement slot, and one shared `recipeRequirements` rule lists requirements for planCraft, salvage and the recipes listing. Research finds regional common and uncommon recipes before the rule recipes, and a regional primary sets craft quality from its rarity.

## What was built

**Task 1: columns and shared rules** (`ef7777a5` RED, `c14b6345` GREEN)
- `recipe_template` gains `req4TemplateId: t.u64().default(0n)` and `req4Count: t.u64().default(0n)` as its last columns. This is the 51.1 defaulted form, and the diff only adds lines.
- `recipeRequirements(recipe)` returns `{ templateId, count }[]` in slot order: req1 and req2 always, req3 when it has a template and a count, req4 when both values are above 0n. Its input type `RecipeRequirementSlots` keeps the req4 fields optional.
- `planCraft` loops over `recipeRequirements` and merges by template as before. `CraftPlanInput` gains optional req4 fields and `primaryMaterialRarity`.
- `primaryMaterialTier(name, rarity?)` and `craftQualityForMaterialName(name, rarity?)`:
  - a MATERIAL_DEFS name keeps its tier;
  - an unknown name maps by rarity: uncommon is 2n, rare/epic/legendary is 3n, anything else is 1n.
- `economy_privacy.test.ts` pins the 15 columns and checks that both new columns are defaulted, non-optional u64.

**Task 2: regional research, kinds, craft, salvage, listing** (`8a5fe1ca` RED, `860e3b48` GREEN)
- `BagMaterial.kind?`: heldParts uses it when it is a real MaterialKind. research_recipes fills it from `economy_item.kind`, so an unmapped regional material such as "Brinewort Crystal" (trinket) joins the 50-25 rule recipes.
- research_recipes handles regional recipes first:
  - It takes `region_recipe` rows with learnBy 'research', sorted by recipeTemplateId.
  - A recipe is discovered only when the bag holds every requirement (merged per template).
  - These discoveries count toward the shared limit of 3 and write the existing "You discover ..." line.
  - The rule loop then runs with the same count.
- craftBatch passes `primaryMaterialRarity: req1Template?.rarity`.
- salvage_item builds each recipe's parts from `recipeRequirements`.
- The 'recipes' text listing in `intent.ts` loops over `recipeRequirements`. The text format is unchanged.
- `regional_recipes.test.ts` runs the real handlers on the strict mock and covers:
  - discover, short requirement, scroll-only, ordering/limit, rule kind, rule insert columns;
  - 4-requirement craft and short-4th refusal;
  - uncommon to reinforced and common to standard quality;
  - learning rare and legendary scrolls;
  - salvage returning all four parts.
