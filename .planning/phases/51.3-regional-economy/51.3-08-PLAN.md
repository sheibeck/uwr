`parseDialValue(token)`: matches `^[+-]?\d{1,6}%?$` and returns a bigint, else null.

`parseEconomyCommand(text)`:
- The trigger is `^/economy(?:\s|$)` (case-insensitive). Tokens split on whitespace; verbs are lowercased.
- Region and item names are the tokens between the keyword and the last one or two tokens, joined by single spaces.
- Every malformed form gives `{ verb: 'help' }`.
- Return types are a discriminated union: show, set (scope global or tier), region_set, region_reset, region_show, item_set, item_reset, ai, reset, help.

`handleEconomyAdminCommand(ctx, character, text): boolean`:
- It returns false when the parse gives null.
- The admin check comes first. A non-admin gets `fail(ctx, character, ECONOMY_ADMIN_REFUSAL_LINE)`, and the function returns true having written nothing else.
- `say` is the system line writer.
- Each verb:
  - **Set forms** call `applyDialChange` and report the stored value. The dial name is capitalised (Rarity, Drop rate, Gold, Gather rate, Boss bonus, `<Tier> weight`). Percent dials end with %. A clamped result adds `(N% is the most)` or `(N% is the least)`, and the shift dials add `(N is the most)` or `(N is the least)`.
  - **Refusals from applyDialChange** produce in-voice plain lines: 'No region by that name.', 'No item by that name.' or the usage line.
  - **region_show** prints the region's effective dials, marking each dial that is overridden in that region, the region_economy status (or 'on fallbacks'), and the counts of economy_item rows, enemy_loot_entry rows and region_recipe rows for that region.
  - **show** prints the global dials, the tier weights, 'AI economy: on' or 'AI economy: off', the counts of economy_region_dial and economy_item_dial rows, and the region counts by region_economy status, plus the regions with no row (on fallbacks).
  - **ai** calls setAiEnabled. On: 'AI economy: on. New regions will get an AI-designed economy.' Off: 'AI economy: off. Regions use the rule-based economy.'
  - **reset** calls resetEconomy('global') and says 'Economy dials reset to defaults. The AI economy switch was left <on|off>.'
  - **help** says the usage line.
- Every name echoed back passes through a local `plainText(s)` that removes `[ ] < > { }`.

Tests first (RED): `helpers/economy_admin_commands.test.ts` on the strict mock with the recording schema, as in llm_admin_commands.test.ts. Then the implementation (GREEN).
