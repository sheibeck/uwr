# Phase 51.3 Plan 08: Economy admin command and reducers Summary

`/economy` lets the admin show, set and reset every economy dial from the console, and three admin-only reducers give the Phase 52 panel the same clamped write path.

## Grammar (case-insensitive; values are whole numbers, optional sign, optional trailing %, at most 6 digits)

- `/economy` or `/economy show`: global dials, tier weights, AI switch, region override and item pin counts, regions by status (designed, pending, failed, on fallbacks; a region with no region_economy row is on fallbacks)
- `/economy rarity|drop|gold|gather|boss <value>`
- `/economy tier common|uncommon|rare|epic|legendary <pct>`
- `/economy region <name...>` (effective dials, "(set for this region)" marks, status, economy_item / enemy_loot_entry / region_recipe counts)
- `/economy region <name...> rarity|drop|gold|gather|boss <value>`
- `/economy region <name...> reset` (no override: "<Region> has no overrides.", nothing written)
- `/economy item <name...> drop <pct>`, `/economy item <name...> reset`
- `/economy ai on|off`, `/economy reset` (keeps the AI switch, says so)
- Anything malformed prints `ECONOMY_COMMAND_USAGE` through fail() and writes nothing. A stranger gets `The Keeper does not open his ledgers to you.` and nothing is written.
- Clamp report: `Gold set to 300% (300% is the most).`; shift dials show bare numbers (`Rarity set to 2 (2 is the most).`).
- Names are matched case-insensitively with whitespace collapsed; echoed names (the stored name) have `[ ] < > { }` removed.
