- CUT-01: kills drop loot again; today `loot_table` has zero rows, so nothing drops.
- SC2: the rarity mix rises by level, is better for bosses and named foes, and legendary comes only from them.
- SC4: a kill is never empty.
- SC5: every roll reads the dials.

The loot UI stays as it is (Phase 51.4).
Output: `helpers/loot.ts`, the handleVictory rewrite, and unit and real-reducer integration tests.
