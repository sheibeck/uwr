### `salvageRoll` to `economyRoll` (utility, transform)

**Analog:** `data/crafting_rules.ts` 835-853.

```typescript
export const SALVAGE_REAGENT_ROLL_INDEX = 100n;
export const SALVAGE_SCROLL_ROLL_INDEX = 101n;
export function salvageRoll(seed: bigint, index: bigint): bigint {
  let z = BigInt.asUintN(64, seed + (index + 1n) * 0x9e3779b97f4a7c15n);
  z = BigInt.asUintN(64, (z ^ (z >> 30n)) * 0xbf58476d1ce4e5b9n);
  z = BigInt.asUintN(64, (z ^ (z >> 27n)) * 0x94d049bb133111ebn);
  z = z ^ (z >> 31n);
  return z % 100n;
}
```
`economyRoll` returns the full `z ^ (z >> 31n)` (drop the `% 100n`); `rollBelow(seed, i, n) = economyRoll % n`. ### Error handling and fallbacks
- Model-number clamps: `toBigIntSafe(v, { min, max, fallback })` from `helpers/safe_numbers.ts` (used in `applyRenownPerkResult`).
- Apply never fails the host job: try/catch with `console.error` (precedent: `applyRenownPerkResult` parse try/catch, line ~990-999; fill hook per RESEARCH).
- Player-facing refusals use `fail(ctx, character, msg)` (memory preference); `SenderError` only in admin reducers and helpers with no character.

### Determinism
Reducers use `ctx.timestamp.microsSinceUnixEpoch` and ids only; splitmix via `economyRoll`; never add offsets to a raw seed.
