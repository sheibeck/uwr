## Decisions (coordinator defaults, reported to the owner; the owner may still override)
- **A1, own side for the sweep (plan 51-03):** the visited row records `fromLocationId`, the place the character arrived from the last time it entered this place. Respawn, resurrection, first spawn and the backfill pass no origin.
- **Decision 5, backfill:** set_active_character marks the character's current place visited (insert when missing, never touching fromLocationId), and every move also inserts the origin when it has no row, so characters that existed before this phase see their place at once.
- **A9, look copy:** plain deterministic server copy (below). It is not Keeper text and needs no prompt change. Recorded for the owner's glance at UAT.

## Exact copy (server)
- Neighbour place, line 1: the place name. Line 2: `Next to {here}.` when the place is in the current place's region, else `Next to {here}, across the border in {Region}.` (Region is the place's region name; fall back to `another region` when the region row is missing). Line 3: the description when it is not empty; for a place whose terrainType is `uncharted` and whose description is empty, `Nobody has been here yet.`; otherwise no third line. Lines join with a newline, like the other look answers.
- Bind stone (only when the current place has `bindStone`): line 1 `Bind stone`; line 2 `You are bound here. You return here after defeat.` when `character.boundLocationId === location.id`, else `You are not bound here. Bind here to return after defeat.`
