<objective>
Make every schema change this phase needs, additively, in one place: defaulted last columns that hold round counts (in-combat ability cooldowns, enemy ability cooldowns, wind-up rounds, add arrival round, round start time) and a new private `combat_moment` table for the once-per-fight moment flags and the per-fight budget. Teach the schema recorder to see `.default(...)`, pin the RND-04 table shapes with a schema test, and write the new columns at every existing insert site.

Purpose: RND-04 (round number, deadline and chosen action in public tables: the existing public `combat_round` and `combat_action` are reused per CONTEXT) and RND-03 (rounds are stored on the rows the engine reads). Additive-only keeps the later local publish free of `--clear-database`, which would wipe the stored Anthropic key.

Output: schema edits, recorder flag, schema test with a source scan, explicit new-column writes at five existing inserts. No publish here: 46.1-09 publishes once after all schema and code work.
</objective>
