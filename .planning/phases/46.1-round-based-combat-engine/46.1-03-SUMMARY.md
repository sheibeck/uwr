## What changed

- `combat_narration.ts`: `RoundEventSummary.narrativeType` adds `kill`, `near_death`, `phase`, plus optional `momentSubject`, `momentFirst`, `momentBossOrNamed`. New `CombatMomentFacts`, `finalCombatRound` (max `combat_round.roundNumber`, 0n when none, never throws), `buildCombatMomentSummary`, `enqueueCombatMomentNarration`. A shared private `enqueueNarrationJob` builds the request for both the outro and moments (leader's player, else the first participant's; empty participant list writes nothing; refusal silent; errors logged redacted). The outro now uses the final round for its source key, request and summary; with no round rows it stays `0`. File header updated.
- `llm_layers.ts`: private `buildCombatMomentVolatile` (lines in the plan's order, names through the existing `nameRenderer`, no HP numbers, no pronoun for the subject). `buildCombatNarrationVolatile` now dispatches victory/defeat to the outro, kill/near_death/phase to the moment builder, the rest to the round builder. The only removed lines are the old dispatcher body.
- `46.1-VOICE-ADDENDUM.md`: M1, M2, M3, M4, M5, M6a, M6, M6b, M7, M8 exactly as shipped, marked auto-approved overnight, owner to review.
