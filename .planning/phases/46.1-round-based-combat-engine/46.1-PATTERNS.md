## Shared Patterns

### Module-identity guard (scheduled reducers)
**Source:** `reducers/llm_executor.ts:37-40` and `helpers/llm_executor.ts:620`. **Apply to:** `resolve_round_timer`, and `combat_loop` and `resolve_pull` if touched.

### Scheduled table primary key
**Source:** project memory plus `clearCombatArtifacts` (`roundTimerTable.scheduledId.delete(row.scheduledId)`). **Apply to:** every tick delete, find or update.

### Failure messaging
Use `fail(ctx, character, msg, 'combat')` where a character exists (`failCombat` / `failItem` wrappers are used in the reducers). `SenderError` only in helpers with no character.

### Determinism
Use `ctx.timestamp` only. Seed style is `nowMicros + character.id * 37n + target.id`, plus `roundNumber * 104729n`. Sort by id explicitly; never rely on `filter()` or `iter()` order.

### Additive migration
New columns: defaulted and last. No removed or modified columns. No dropped non-empty tables. If a clear ever looks needed, STOP and ask the owner (a clear wipes the stored Anthropic key).

### Narration budget
The real global gate is the refusal inside `enqueueLlmJob`; ignore refusals. The per-fight cap (3 moments + 1 end) is counted from `combat_moment` rows, and a row is written when a moment fires even if the enqueue is refused. `NARRATION_BUDGET_THRESHOLD` and `MAX_COMBAT_NARRATIONS` are unused today (wire the latter to the cap or remove it).
