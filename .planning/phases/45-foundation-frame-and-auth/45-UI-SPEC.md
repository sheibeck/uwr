# Phase 45 — UI Design Contract

> Visual and interaction contract for Phase 45: Foundation, Frame and Auth. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Design source (imported fresh 2026-10-05, never cached): Nocturne `_ds/styles.css` + `_ds/readme.md`; Ledger screens 2i (Console · Explore) and 2b (Inventory, for the drawer and sheet shell); Console & Combat 1a/1c (Ledger direction only; 1a is identical to 2i). The design contains **no** splash, sign-in, character-picker, banner or More-sheet screen; those are specified here from Nocturne rules and flagged in Assumptions.
>

## Frame Contract

### Breakpoint

One layout breakpoint: **900px**. `min-width: 900px` is desktop (three columns); below is mobile (strip, feed, tab bar). Verification sizes: 1280x800 and 390x844. The mock shows only these two frames, so 900 is the CONTEXT value, not a design value (Assumption A4). At 900 the feed column is 360px wide; both rails keep their widths.

One non-layout threshold: header screen-button **labels hide below 1100px** (icons only, `aria-label` and `title` keep the name), because header content is about 1060px wide at full labels. Implement with a container query on the header, not a second layout mode.

The app root is `height: 100dvh; overflow: hidden`. No page scroll. Each region scrolls inside itself (`overflow-y: auto`, `min-height: 0`). No device bezel and no corner radius on the frame (the mock's 10px and 28px are canvas framing).

### Screen state (both layouts)

- State is one value, `activeScreen`: `null | 'map' | 'bag' | 'stats' | 'craft' | 'social' | 'events' | 'vendor' | 'more'`. Opening another replaces it; there is never more than one drawer or sheet. Clicking the open screen's header button closes it (desktop). Crossing the 900px breakpoint with a screen open keeps the same screen and re-renders it as drawer or sheet; `more` on desktop maps to `null`.
- Esc closes the drawer or sheet. The close button closes it. After closing, focus returns to the element that opened it (header button, tab, or More row's parent tab). While open, focus is kept inside the drawer or sheet (Tab and Shift+Tab cycle its focusable elements; the close button is first in order). Tab is pulled back in only when focus is lost (on the page body) or already inside; focus on the header, rail or tab bar beside the dialog is left alone so that navigation stays keyboard-reachable. Opening moves focus to the close button. `role="dialog"`, `aria-labelledby` the title `h4`; `aria-modal="true"` on the mobile sheet (full-height overlay) and `aria-modal="false"` on the desktop drawer (non-modal side panel).
- Mouse and touch remain live on the header and rails while the drawer is open (header buttons swap the drawer). Esc is ignored when the account menu is open (the menu consumes it first).

### Splash / sign-in (FND-07)

- Layout: single centered column, `min-height: 100dvh`, `padding: 48px 24px` desktop and `24px 16px` mobile, `gap: 24px`, content left-to-right centered (Nocturne's left-aligned rule yields to a single-focus splash; Assumption A8).
- Logo: `<img src="/assets/logo.png" alt="Unwritten Realms" width="1672" height="941">` with classes `lighten`. Sizing rule (the same rule the discarded old test enforced): `width: min(960px, 100%); max-height: calc(100dvh - 176px); aspect-ratio: 16 / 9; object-fit: contain; height: auto; flex-shrink: 0; border-radius: var(--radius-lg); user-select: none;`. **No** `image-rendering: pixelated` and no fixed small max-width. Resulting sizes: 960x540 at 1280x800, 342x192 at 390x844, never distorted, never cropped. It is a dark key-art photograph; `.lighten` lets its darkest values melt into the ground per Nocturne (Assumption A9).
- Sign in button: `.btn .btn-primary`, `PhSignIn` 18px + `Sign in`, `min-height: 44px`, `padding: 0 24px`; on mobile `width: min(342px, 100%)`. Enter on the page also triggers it. It is enabled without a live DB connection (the PKCE redirect needs none).
- Status line under the button (Label 12, `--color-neutral-300`, `aria-live="polite"`, reserve 24px so nothing jumps): the states below. Error line (`role="alert"`): `PhWarningCircle` 16px in `--color-health` + message in `--color-neutral-200`, on a `color-mix(in srgb, var(--color-health) 18%, transparent)` tint, `padding: 8px 16px`, `--radius-md`, `max-width: 440px`.

| Splash state | When | Button | Status |
|--------------|------|--------|--------|
| idle | no stored token | enabled | none |
| redirecting | PKCE start | disabled (Nocturne 45% opacity) | `Redirecting to SpacetimeAuth…` with `PhCircleNotch` spinner |
| connecting | token present, socket opening or `login_email` pending | hidden | `Connecting…` with spinner |
| signing in | connected, `player.userId` still null | hidden | `Signing in…` with spinner |
| session expired | token rejected or expired | enabled | error line: `Your session expired. Sign in again.` |
| sign-in failed | callback or redirect threw | enabled | error line: `Sign-in failed. Try again.` |
| unreachable | first connection cannot open | enabled | `Can't reach the server. Retrying…` (see backoff below) |

A stored token on reload goes straight to `connecting` (no flash of `idle`). Spinner: `PhCircleNotch` rotating 1s linear infinite; under reduced motion it is static.

- Body: `.card` (surface, `--radius-lg`, `padding: 24px`) `width: min(440px, 100% - 32px)`, horizontally centered, `margin-top: 48px` desktop and `24px` mobile; `h4` `Choose a character`; then a vertical list (`gap: 8px`) of row buttons.
- Row: full-width `button`, `min-height: 56px`, `padding: 8px 16px`, `--radius-md`, background `var(--color-bg)`, avatar square 36px with initial, name Body 14/500, `Lv N · Race Class` Label 12 `--color-neutral-400`, `PhCaretRight` 16px `--color-neutral-500` right. Hover tint `color-mix(in srgb, var(--color-text) 7%, transparent)`, pressed 14%, `:focus-visible` Nocturne ring. `aria-label="Play as {name}"`. Long names truncate with ellipsis.
- Selecting a row calls `set_active_character` with that id. While pending, every row is disabled (45% opacity) and the chosen row shows a `PhCircleNotch` spinner instead of the caret. On a reducer error: error line above the list, `Couldn't open that character. Try again.`, rows re-enabled. Success needs no message; the frame replaces the picker when `player.activeCharacterId` arrives.
- Order: oldest first by `createdAt` (stable; Assumption A10). No auto-select when there is exactly one.

### No characters yet

Same pre-frame header (title `Characters`) and a centered `.card` (same size): `card-kicker` `No characters yet`, `card-title` `Character creation is not ready yet`, `card-body` `Check back soon. Until then, sign in with an account that already has a character.`, then a `.btn .btn-secondary` `Log out`. No illustration.

### Notice bars (Reconnecting and version reload)

In-flow bars (they push the frame down, they do not overlay it), `height: 32px`, `padding: 0 16px`, Label 12, `display: flex; align-items: center; gap: 8px`, full width, directly under the header (desktop) or under the vitals strip and location row (mobile). Max two shown at once; Reconnecting is first.
- Reconnecting: background `var(--color-surface)`, `PhCircleNotch` accent spinner, `Reconnecting…` in `--color-neutral-200`, then `Next try in {n}s` in `--color-neutral-500`, counting down. `role="status"`, `aria-live="polite"`. The frame keeps showing the last data, interactive controls that call reducers are not disabled in this phase (nothing sends yet). Retries use backoff 1s, 2s, 5s, then up to 30s (cap); the notice appears on the first drop and disappears on reconnect with no success toast. An expired or rejected token skips retries: session cleared, back to the splash in the `session expired` state.
- Version reload: background `color-mix(in srgb, var(--color-accent-800) 55%, transparent)`, `PhArrowClockwise` 14px, `A new version is ready.` in `--color-accent-300`, spacer, `.btn .btn-primary` `Reload` (`padding: 4px 16px`, Label 12 size inside the bar). Not dismissible, not modal; reload is the player's choice. Appears when `app_version.version` differs from `__BUILD_VERSION__`.

## Assumptions (decided here, not asked)

- **A1. Spacing is two layers.** Nocturne `--space-*` stays inside Nocturne component classes; frame layout uses the 4-multiple px scale above. The mock itself uses raw px; the adherence lint's raw-px rule is `warn` only and is not enforced.
- **A2. Resource-bar colors are a second sanctioned extension.** Nocturne has no red, blue or amber, and the mock draws health, mana and stamina in `oklch()` literals. They become `--color-health/mana/stamina` in the client token file. The same `--color-health` serves error text and tint (no separate danger token).
- **A3. Frame structure constants** (header 48, rails 252 and 288, 760 feed line) are copied from the mock with 2px normalization; they are layout constants, not new color or type tokens.
- **A4. Breakpoint 900px** is from CONTEXT; the design shows only 1280 and 390 frames. The 1100px header label collapse is an added non-layout threshold.
- **A5. Time of day is `Day` or `Night`** from `world_state.isNight`; the mock's `Dusk, 19:40` has no source in the schema and no server change is allowed in this phase.
- **A6. Motion** (drawer 160ms, sheet 200ms, spinner 1s) is not defined by Nocturne; short and disabled under `prefers-reduced-motion`.
- **A7. No swipe-to-dismiss** on the sheet in Phase 45; the visible close button and Esc are the dismiss paths.
- **A8. Splash is centered**, an exception to Nocturne's left-aligned direction because it is a single-image, single-action screen.
- **A9. Splash logo uses `.lighten`** per Nocturne's image rule, with `--radius-lg`. If review finds it flattens the art's blacks against `--color-bg`, fall back to no blend plus `box-shadow: var(--shadow-md)`.
- **A10. Picker order** is oldest first by `createdAt`; no "last played" field exists.
- **A11. Level-up and New-skill tags are display-only** in Phase 45 (Phase 47 wires the actions, per the old client's pending-level logic).
- **A12. Combat header** (disabled screen buttons at 45% opacity and an `In combat · Round N` tag, mock 1c) is a Phase 48 concern; the header component accepts a `disabled` prop so it can be added without a layout change.
- **A13. Nocturne's font `@import`** (Google Fonts) is used as shipped; offline falls back to `system-ui`. Self-hosting Inter is a later option, not part of this contract.
