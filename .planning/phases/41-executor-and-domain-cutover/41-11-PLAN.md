<objective>
Move combat narration, second in the locked order, onto the executor as a victory/defeat outro that can never touch combat itself.

Purpose: PIPE-07 (narration never blocks combat and is dropped if late) and PIPE-01 for narration. Implements CONTEXT "Combat narration never blocks combat and has the lowest priority" and the research-driven decision "Combat narration covers only the victory/defeat outro ... Enqueue from handleVictory/handleDefeat, and build the summary before clearCombatArtifacts". Combat is real-time (no round hook), so the old round trigger (which has no callers) is deleted. Mid-fight narration is out of scope (it needs a new event model).
Output: rewritten `helpers/combat_narration.ts`, two call sites in `reducers/combat.ts`, tests, allowlist shrink, local publish and a green build.
</objective>
