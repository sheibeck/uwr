<objective>
Let players start fights from the new client. After trying Phase 48 on the local stack, the owner reported: "the UX doesn't have the pull buttons, also doesn't highlight the enemies in any way to make them attackable".

This plan does four things:
- subscribes to `enemy_spawn` for the active character's location, plus the spawns' enemy templates (for level and difficulty)
- adds enemy rows with Careful pull and Body pull actions to Nearby, which the desktop rail and the mobile Map sheet share
- makes the names of available enemies feed keywords (a click starts a careful pull)
- wires both actions to the existing `start_pull` reducer

Client-only: NO server change.

Purpose: there is no way to start combat from the v3.0 client today.

Output:
- `src/rails/enemies.ts` (pure derivation) and its tests
- new GameData fields and a new ConsoleApi action
- the enemy keyword kind
- enemy rows in NearbyList
- tests for all of the above
</objective>
