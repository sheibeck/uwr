<objective>
Fix two issues the owner reported while playing locally on 2026-10-06:

1. Clicking an underlined resource-node keyword (for example "Iron Shard") sends `look at Iron Shard`. Today the server's look handler only checks NPCs, enemies and players, and it never strips the "at". So every node click ends with "You don't see ... here." Make `look <target>` also describe resource nodes at the character's location and items in the character's own inventory.
2. Multi-line server messages such as `help` are joined with a newline, but the feed renders text nodes with normal white-space, so the newlines collapse. Apply `white-space: pre-line` to the server-text body in FeedLine.vue.

Purpose: a click on an underlined name should never dead-end, and help, look and quest lists should be readable.
Output: a new server helper `spacetimedb/src/helpers/examine.ts` with tests, a slimmer LOOK block in `intent.ts`, a local publish (code only, no clear), and a CSS change in `FeedLine.vue` with tests.
</objective>
