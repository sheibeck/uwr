# Phase quick-261006-a13 Plan 01: Action progress bar for gathering and casting Summary

While the active character gathers or casts out of combat, a row directly above the hotbar shows "Gathering {node}" or "Casting {ability}", a filling bar and the seconds left, then "Finishing…" until the server deletes the row.

## What was built

- `src/action/actionProgress.ts`: pure label derivation (`currentAction`), first-seen keys (`actionKeys`), start-time resolution (`actionStartMicros`), progress math (`actionProgress`: fraction, ceil seconds, finishing, clamping) and copy (`actionTimeText`, `actionSummary`).
- `src/action/useActionProgress.ts`: first-seen map per row key (synchronous watch on a key signature) and one `useCooldownTicker` that runs only while an action is shown. Returns null while `combat.active` (the round row owns the slot).
- `resource_gather` and `character_cast` are subscribed per character (`character_id` WHERE plus a matching filter), in `keyedAll`, exposed as `GameData.gathers` and `GameData.characterCasts` with inert empty defaults. The edits to the shared game files are additions only, plus one header-comment line extension in `gameData.ts`.
- `src/action/ActionRow.vue`: one root `div.action-row` with `v-if` (a hidden row is a comment node, so the Phase 48 composer-first-child tests stay green). Icon (PhCube, or `abilityIcon(kind)` for a cast), label, `role="progressbar"` (percent 0 to 100, `aria-valuetext` the summary), seconds cell. No buttons. Existing tokens only, reduced motion removes the width transition.
- `FeedShell.vue`: `<ActionRow />` between `<RoundRow />` and `<HotbarRow />`, plus one comment sentence.

## Decisions

- **Gather start is the first-seen time.** The server's gather duration constant lives in a server-only helper and is shortened by the gatherSpeedBonus perk, so it is not a trustworthy total. Nothing is duplicated on the client.
- **Cast start is min(first seen, endsAt minus castSeconds).** Seen at insert with a mana-floored total: the bar measures from the first-seen time (the floored total). Seen mid-cast: it measures from the exact castSeconds start. No import of the server's mana floor.
- **Cast over gather.** If both rows exist the cast shows; the gather resumes with its original first-seen start once the cast row is deleted (first-seen tracks every row of the character, not only the shown one).
- **No Cancel control.** `src/module_bindings` has no cancel reducer for gather or cast.
- Reduced motion: no width transition, and the shared ticker steps once per second.
