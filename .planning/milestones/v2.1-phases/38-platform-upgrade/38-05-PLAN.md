       - It exits 1 if any check failed, otherwise 0.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser/CLI → Worker `/api/*` | Bearer secret gates access to a paid OpenAI key |
| Worker → OpenAI API | The real key leaves the machine (local wrangler dev only) |
| npm registry → llm-proxy deps | New versions; esbuild and workerd run install scripts |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38-13 | Information disclosure | `.dev.vars` secrets during smoke tests | high | mitigate | The script reads the secret without echoing it and passes it through a chmod-600 header temp file (never on the command line). Key-like strings in error output are redacted. Shell tracing is never enabled. The acceptance check proves no secret value is in the committed script, and `.dev.vars` is confirmed gitignored |
| T-38-14 | Tampering | Accidental production deploy of the Worker | high | mitigate | No `wrangler deploy` in any form and no `deploy`/`secret:*` scripts (prohibitions). Only `wrangler dev` bound to `127.0.0.1` |
| T-38-15 | Spoofing | Auth middleware regression after the hono upgrade | medium | mitigate | Smoke check (b) proves an unauthenticated POST still returns 401 before and after the upgrade |
| T-38-16 | Tampering | Input validation regression | low | mitigate | Smoke check (c) proves missing fields still return 400 |
