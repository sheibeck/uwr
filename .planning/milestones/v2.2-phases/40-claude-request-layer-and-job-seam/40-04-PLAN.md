| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-40-02 | Information disclosure | llm_job / llm_call_log (prompts, outputs, request context) | high | mitigate | no `public` flag on either table; generic test that every llm_* table except the legacy llm_task is private; no prompt/header/key columns (test); bindings check in Plan 40-09 |
