Hard rules for this plan:
- Procedures have no `ctx.db`: every read and write goes through `ctx.withTx(tx => tx.db...)`. `withTx` bodies are synchronous and may run more than once: assign outer variables only from a callback's return value, never mutate outer state inside it (RESEARCH Pitfall 7).
- Never hold a transaction across the call. `Date.now()` is used only through `deps.nowMs`, outside any `withTx` (RESEARCH A5). No `Math.random()`.
- `ctx.sender` appears only in the module-identity guard; apply and failure always act for `job.playerId` (RESEARCH anti-pattern).
- The key comes only from `llm_config` row 1 inside tx1, goes only into `buildClaudeHeaders`, and is passed as a needle to every classify, log and console path. Never read or print `spacetimedb/.env.local`.
- `llm_executor.ts` must not import the SpacetimeDB server entry, `schema/tables`, `index.ts` or `reducers/*`; registration is Plan 41-07. `TimeDuration` comes from the `spacetimedb` root package.
- Test files build fake keys from fragments. Tests: `pnpm --dir spacetimedb exec vitest run --maxWorkers=1 <files>`. Stage by explicit path; every commit ends with the two attribution lines.
</context>

## Flagged assumptions

- Spec-less probe item 13 (PIPE-07, unclassified): "late" is measured from the job's `createdAt` (the moment combat resolved and the outro was enqueued) to the claim transaction and to the persist transaction, both on the module clock. Client render latency is not measured. Exactly 20 s is on time; more than 20 s is late.
- RESEARCH A2: scheduled procedures are private by default in 2.x (search summary, not read from the docs page). The module-identity guard is kept regardless and tested.
- RESEARCH A4: whether Anthropic bills a call the client timed out on is unknown. The design is safe either way: the phase ledger is charged the reservation, the player nothing.
- RESEARCH A7: deterministic jitter from the job id and a second seed spreads retries enough at this scale; if herding shows up in Phase 43 measurements, switch to `ctx.random` outside `withTx`.
